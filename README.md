# Tashi-sysins-repo

FF14（Dalamud）向けプラグインの配布リポジトリです。

## 導入のしかた

1. ゲーム内で `/xlsettings` を開く
2. 「実験的機能」タブを開く
3. 「カスタムプラグインリポジトリ」に次の URL を貼り付ける

```
https://raw.githubusercontent.com/Tashi-sysins/Tashi-sysins-repo/main/repo.json
```

4. 「+」で追加して「保存して閉じる」
5. `/xlplugins` を開くと、一覧に出ます

## 配布しているもの

### AutoTreasure（魔紋自動周回）

「古ぼけた地図」の宝探しを、最初から最後まで自動で回します。

```
地図を使う → 座標を特定 → テレポ → 現地へ移動 → ディグ
  → 宝箱 → 戦闘 → ロット → 転送魔紋に入る
    → 魔紋の中を進む → 脱出 → 次の周回へ
```

**必要なもの**

| プラグイン | 役割 |
|---|---|
| BossMod Reborn | 範囲攻撃の回避・立ち位置 |
| Rotation Solver Reborn | 攻撃と回復のスキル回し |

移動に使う vnavmesh は**取り込み済み**なので、別に入れる必要はありません。
すでに vnavmesh を使っていても競合しません。

**LazyLoot を入れている場合**

ロットは LazyLoot に任せます。こちらのロット設定は画面に出ません。
LazyLoot の設定をそのまま使ってください。

**複数のキャラクターで動かす場合**

1台のパソコンで複数のクライアントを立ち上げて、足並みを揃えられます。
パーティを組んでおけば、リーダーとメンバーは自動で決まります。

地図を使う人は「古ぼけた地図の使用順番」で決められます。

- 指定キャラのみ使用
- 1個ずつ順繰り交代
- 設定消費数後に交代

**別のパソコンとの連携には対応していません。** 同じパソコンの中だけです。

### Bard Performance Recorder（演奏の記録）

近くのプレイヤーが演奏した音符を観測して、**MIDI ファイルに書き出します。**

```
他のプレイヤーが演奏
  → 自分のクライアントに届いた演奏データを記録
    → performance_日時.mid ＋ .json ＋ .txt
```

**必要なプラグインはありません。** 単独で動きます。

**できること**

| | |
|---|---|
| ソロ・合奏 | **どちらも記録できます**（合奏は最大8人まで） |
| ずっと記録する | 押しておくと、**曲ごとに自動で区切って保存**します（演奏会向け） |
| 楽器 | **28種すべて判別**し、トラック名に楽器名を入れて出力します |
| 弾き直し | MidiBard2 用の設定(.json)も同時に出るので、**読み込むだけで同じ編成**で弾けます |
| 演奏者の選択 | 記録後に選び直して書き出せます。**無関係な演奏を後から除けます**（録り直し不要） |

**できないこと**

- **テンポと強弱**はパケットに含まれないため復元できません
- **音の長さは推定値**です。単音はほぼ正確ですが、**和音では長めに出ます**
- **自分自身の演奏は記録できません**（自分のクライアントには送り返されないため）
- 元の MIDI ファイルをそのまま復元するものではありません

ゲームへの送信・演奏操作は一切行いません（受信の観測のみ）。

仕組みの詳細は
[技術資料](https://github.com/Tashi-sysins/BardPerformanceRecorder/blob/main/docs/技術資料_パケット取得とMIDI化_20260922.md)
にまとめてあります。

ソースコード：https://github.com/Tashi-sysins/BardPerformanceRecorder
