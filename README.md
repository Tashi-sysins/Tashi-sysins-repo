# Tashi-sysins-repo

FF14（Dalamud）向けプラグインの配布リポジトリです。

## 導入のしかた

1. ゲーム内で `/xlsettings` を開く
2. 「実験的機能」タブを開く
3. 「カスタムプラグインリポジトリ」に次の URL を貼り付ける

```
https://raw.githubusercontent.com/Tashi-sysins/Tashi-sysins-repo/main/repo.json
```

4. 「+」で追加して「保存して閉じる」
5. `/xlplugins` を開くと、一覧に出ます

## 配布しているもの

### AutoTreasure（魔紋自動周回）

「古ぼけた地図」の宝探しを、最初から最後まで自動で回します。

```
地図を使う → 座標を特定 → テレポ → 現地へ移動 → ディグ
  → 宝箱 → 戦闘 → ロット → 転送魔紋に入る
    → 魔紋の中を進む → 脱出 → 次の周回へ
```

**必要なもの**

| プラグイン | 役割 |
|---|---|
| BossMod Reborn | 範囲攻撃の回避・立ち位置 |
| Rotation Solver Reborn | 攻撃と回復のスキル回し |

移動に使う vnavmesh は**取り込み済み**なので、別に入れる必要はありません。
すでに vnavmesh を使っていても競合しません。

**LazyLoot を入れている場合**

ロットは LazyLoot に任せます。こちらのロット設定は画面に出ません。
LazyLoot の設定をそのまま使ってください。

**複数のキャラクターで動かす場合**

1台のパソコンで複数のクライアントを立ち上げて、足並みを揃えられます。
パーティを組んでおけば、リーダーとメンバーは自動で決まります。

地図を使う人は「古ぼけた地図の使用順番」で決められます。

- 指定キャラのみ使用
- 1個ずつ順繰り交代
- 設定消費数後に交代

**別のパソコンとの連携には対応していません。** 同じパソコンの中だけです。
